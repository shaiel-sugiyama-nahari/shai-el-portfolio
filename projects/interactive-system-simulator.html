Interactive System Simulator

Overview

Project summary

This simulator presents a complex system through an interactive 3D interface. Users can explore individual controls, move between guided steps, and view contextual information connected to specific parts of the system.

The project combines interface design, 3D interaction, camera movement, highlighted components, and structured learning screens. This portfolio presentation focuses on the interface, interaction flow, and visual learning experience shown in the available screenshots.
